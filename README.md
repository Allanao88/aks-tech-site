AKS - Tech

Site institucional da AKS - Tech, desenvolvido com React, TypeScript e Vite.

## Requisitos

- Node.js compatível com a versão do Vite utilizada
- npm

## Desenvolvimento local

Instale as dependências:

```bash
npm install


Inicie o servidor de desenvolvimento:
npm run dev


Validação
Execute o ESLint:
npm run lint


Gere a versão de produção:
npm run build


Os arquivos de produção são gerados na pasta dist.
Publicação na Vercel
Configuração recomendada:
- Framework Preset: Vite
- Build Command: npm run build
- Output Directory: dist
- Install Command: npm install
Estrutura do projeto
- src/components/ — componentes compartilhados, como cabeçalho e rodapé.
- src/features/home/ — seções da página inicial.
- src/features/contact/ — funcionalidade de contato.
- src/styles/ — tokens visuais e estilos das seções.
- public/images/ — imagens e recursos estáticos.
Tecnologias
- React
- TypeScript
- Vite
- CSS
  EOF
